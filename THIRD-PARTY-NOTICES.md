## Parser

The OOXML parser is [parasma-ooxml](https://github.com/spearsandshields/parasma-ooxml),
Parasma's fork of [pterror/ooxml](https://github.com/pterror/ooxml) by the
ooxml contributors. Parasma depends on seven of its crates — `ooxml-opc`,
`ooxml-xml`, `ooxml-dml`, `ooxml-omml`, `ooxml-wml`, `ooxml-sml` and
`ooxml-pml` — as a git dependency pinned by tag in the root `Cargo.toml`
`[patch.crates-io]` block. The fork is not published to crates.io; the
`ooxml-*` crates there are upstream's.

Upstream licenses the work under `MIT OR Apache-2.0`; Parasma uses it under
the Apache License 2.0. Upstream's copyright notice:

> Copyright (c) 2024 ooxml contributors

The fork's own changes are listed in its `CHANGES-FROM-UPSTREAM.md` and are
offered under the same `MIT OR Apache-2.0` terms as upstream.

`scripts/generate-font-map.py` from LibreOffice's font substitution table,

in the [LibreOffice core](https://github.com/LibreOffice/core) repository.

the Mozilla Public License, v. 2.0, in addition to this repository's Apache
License 2.0. The generator script and the hand-written override tables in it

## Vendored icon paths

The snippet chrome renders its toolbar/panel controls with a small fixed set of
[Lucide](https://lucide.dev) icons (ISC License). The SVG path data for ~15
glyphs is vendored inline in `packages/snippet/src/chrome/icons.ts` (not the
`lucide` npm package) to keep the package dependency-free and the embed footprint
minimal. The ISC license applies to that path data:

## Fonts fetched at runtime

Parasma renders documents with metric-compatible substitute fonts. **No font
binaries are committed to or redistributed from this repository** (the test-font
directory is gitignored and the substitutes are fetched from a public CDN at
runtime, pinned to the upstream commits listed in
`packages/parasma-core/src/font-resolver.ts`). They are listed here because the
running application serves them to end users. Licenses were read from each
project's license file at the pinned commit, or from the font's own name table.

| Font | Substitutes for | Source | License |
| --- | --- | --- | --- |
| Arimo | Arial | googlefonts/arimo | SIL OFL 1.1 |
| Tinos | Times New Roman | googlefonts/tinos | SIL OFL 1.1 |
| Cousine | Courier New | googlefonts/cousine | SIL OFL 1.1 |
| Carlito | Calibri | googlefonts/carlito | SIL OFL 1.1 (Reserved Font Name "Carlito") |
| Caladea | Cambria | googlefonts/caladea | SIL OFL 1.1 |
| Open Sans | Open Sans (real) | googlefonts/opensans | SIL OFL 1.1 |
| DejaVu Sans | DejaVu Sans (real) | `dejavu-fonts-ttf` (npm) | DejaVu Fonts License (Bitstream Vera + Arev; DejaVu changes public domain) |
| Noto Sans Arabic | Arabic coverage | notofonts/notofonts.github.io | SIL OFL 1.1 |
| Noto Sans CJK SC | CJK coverage | notofonts/noto-cjk | SIL OFL 1.1 |
| XITS Math (a STIX fork) | Cambria Math / OMML equation typesetting | aliftype/xits | SIL OFL 1.1 |

When packaging a distribution that redistributes any of these font binaries,
include the corresponding license text alongside them. The SIL Open Font License
also forbids selling the fonts by themselves and, where a Reserved Font Name is
declared, using that name for a modified font.
